### Hi, I'm Nael 👋

Mechatronics engineer turned ML engineer at Bosch, Stuttgart. I spent 2.5 years writing
requirements for ADAS programs. Now I build the models and check whether they meet them.

A score tells you how good a model is. Its failures tell you whether you can ship it.

- 🔭 **Now:** LLM agents that audit other models (LangGraph, MCP, local LLMs)
- 🧪 **Next:** RAG with proper evaluation on technical manuals
- 🤖 **Before ML:** robot arms, mobile robots, embedded motor control
- ⚡ **Fun fact:** my LLM agent copied every number correctly and still got the story wrong.
  So I built a second agent to fact-check the first.

### Projects

| Project | Question | Answer |
|---|---|---|
| [perception-triage-agent](https://github.com/knh4abt/perception-triage-agent) | Can an LLM agent correctly report where an object detector fails? | Only after 5 fixes. The more work moved from the model to code, the more reliable the report got. YOLOv8n, LangGraph, MCP, Reviewer agent. |
| [driving-scene-segmentation](https://github.com/knh4abt/driving-scene-segmentation) | Where do DeepLabV3+ and SegFormer-B0 fail on Cityscapes? | 72.9% vs 60.1% mIoU. The gap is not noise: trucks get labelled as cars. |
| [medvision](https://github.com/knh4abt/medvision) | How far does a small CNN get on colorectal histology? | EfficientNet-B0, 99.6% accuracy on NCT-CRC-HE-100K. |
| [rul-for-nasa-jet-engines](https://github.com/knh4abt/rul-for-nasa-jet-engines) | How long until a jet engine fails? | Random Forest on NASA C-MAPSS, RMSE 46 (75% better than baseline). |
